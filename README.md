### 🛠️ Pipeline tools I build

| Tool | What it does |
|---|---|
| [**USD Bridge – Maya to Houdini**](https://github.com/Aboellief/usd-bridge-maya-to-houdini) | Exports Maya/Arnold scenes to USD and rebuilds them natively in Houdini Solaris (Arnold or Karma), with a Maya→MaterialX shader compiler and Arnold→Karma light conversion |
| **ASP — Asset Scene Packager** | 13,000+ line Maya/Arnold tool that snapshots a production scene to JSON and rebuilds it clean — geometry, materials, cameras, lights, AOVs, render settings — with a matching render |
| [**Scene Cleaner by OBJ**](https://aboellief.gumroad.com/l/eenkq) | Rebuilds a history-free Maya scene via OBJ + JSON snapshot, restoring materials, lights, cameras and render settings |
| [**Arnold Utilities (V4 PRO)**](https://aboellief.gumroad.com/l/ekulxb) | PySide2/Arnold SDK toolkit for batch color-space, emission, naming, subdivision/LOD and AOV Light Group management |
| [**TX Converter**](https://aboellief.gumroad.com/l/mtlwe) | TX conversion for Maya/Arnold scenes with color-space handling and missing-texture reporting |
| **Toon Tool V4 PRO** | Standard Surface ⇄ aiToon conversion and stylized NPR outline controls |
